Reference · sharing

Pass your setup on

Export turns one of your profiles into a line of text you can paste anywhere: Discord, a forum, a whisper. Import turns that text back into a new profile of your own.

Giving

Export a profile

  1. Switch to the profile you want to share

    Export always shares the active one.

  2. Press Export

    On the Profiles settings page, under Share a profile with friends, or type /cine export. A window opens with the text already selected.

  3. Copy it and send it

    Press Ctrl+C (or Select all first if you clicked away), then paste it wherever your friends will see it. It's one long line that starts with CINE1:.

The built-in profiles (Subtle, Balanced and Cinema) can't be exported: everyone has them already. To share your changes to one, make a New profile from it on the Profiles page and export that. If you changed things in Customize, they're already in your own profile, My setup.

Getting

Import a profile

  1. Press Import

    On the Profiles settings page, or type /cine import. An empty box opens.

  2. Paste the text

    Press Ctrl+V. The window says what it is, for example Night Rider, shared by Thrall: 42 settings changed from the defaults, with its description if it has one.

  3. Name it and press Import

    The Save as box starts with the profile's own name. If you already have a profile by that name, pick another. It's added as a new profile and switched to straight away.

Your own profiles stay as they are. To go back, pick your old profile on the Profiles page or with /cine profile.

Commands

The two commands

/cine exportShows the active profile as text to copy
/cine importOpens the box to paste a shared profile into
Inside

What's in the text, and what isn't

In it
The profile's name, its description and icon, the name of the character who shared it, the Cinematic version, and every setting that differs from the defaults.
Not in it
Frames you added yourself (Add mode), and your own zone and time-of-day tint colors, just as with any profile. Nothing else about you or your character.
Safe to paste
The text is only read as settings, never run. Anything that isn't a Cinematic setting of the right kind is left out.
If it won't import

What the messages mean

"That isn't a whole Cinematic profile."
Part of the text is missing, which happens when a copy is cut short. Copy all of it and paste it again. Spaces and line breaks that crept in are fine: they're ignored.
"This profile needs a newer version of Cinematic."
It was made in a format your version can't read. Update Cinematic, then try again.
"... settings from a newer Cinematic will be skipped."
Your friend's version has settings yours doesn't know yet. The rest import fine; update Cinematic to get them all.
"There's already a profile called..."
Change the name in the Save as box.
Does it work between WoW Forever and retail?
The text imports on any version of the game. Each game keeps its own profiles, so import it on the one you'll play it on, and settings that only apply to one game, such as the swing timer, only do anything there.
Also

Sharing wheels

Wheels you make yourself can be shared the same way, from the Your wheels settings page: Share wheel gives a line of text, and Import a wheel adds a friend's as a new wheel of yours. Before you press Add wheel, the window lists every command on it.

Read every command before you add a wheel. Each runs as if you'd typed it, and /run ones can do anything an addon can.
