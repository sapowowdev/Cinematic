Reference · commands

Every /cine command

Type these in the chat box. /cinematic works the same as /cine, and /cine help lists them in the game.

General

On, off and settings

/cineTurns CineMode on or off. With no level picked yet, it opens the welcome window
/cine onTurns CineMode on
/cine offTurns CineMode off
/cine configOpens Cinematic's settings (/cine options too)
/cine hideuiHides the UI but keeps the look: the tint, letterbox and time-of-day title. Again to bring it back
/cine size 3Sets the letterbox bar height, as a percent of the screen from 0 to 40. Each bar starts at 3
/cine buttonShows or hides the minimap button
/cine welcomeOpens the welcome window, to pick a level or Customize
Profiles

Switching and sharing

/cine profileLists the profiles, the active one in yellow
/cine profile CinemaSwitches to the profile with that name (any capitals)
/cine resetPuts the active profile back to how it started
/cine exportShows the active profile as text to copy and share
/cine importOpens a box to paste in a profile someone shared with you

More on these in Profiles and Sharing profiles.

Frames

Fading other frames

For these, point at the frame with the mouse first, then type the command (press Enter to open the chat box without moving the mouse).

/cine addFades the frame under the mouse too, with the rest of the UI
/cine add FrameNameFades a frame by its name instead (names are case-sensitive)
/cine add modeAdd mode: picks up every frame you point at. Type it again to fade them all
/cine add cancelEnds Add mode without fading the frames it picked
/cine keepAlways shows the frame under the mouse (/cine remove too)
/cine listLists the extra frames you've added

The same is on the Advanced Frames settings page. See Other addons.

Camera

The camera

/cine behindSwings the camera back behind your character, keeping your zoom
/cine flybyTurns the camera slowly round to look back, then back behind you. Again to stop
/cine walkSays whether Cinematic thinks you're walking or auto-running, and which camera that brings
/cine walk flipFixes it when it has walk and run backwards

Keys to start each camera, and the camera wheel, are on the Keybinds page.

Extras

Windows of its own

/cine talentsOpens the talent calculator, to plan a build. WoW Forever and Classic
/cine rollsOpens the latest loot rolls, once Roll Vision is turned on. Where the game keeps a loot history
/cine rolls testShows the roll window with made-up rolls, to see how it looks
When something's wrong

Logs and the safety switch

/cine logOpens the log and a summary of your setup, ready to copy into a bug report
/cine log clearEmpties the log
/cine panicStops Cinematic for this session and puts your UI and settings back
/cine resumeStarts Cinematic again after /cine panic or an error stopped it

How to use them is on the Troubleshooting page.
