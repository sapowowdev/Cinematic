Help · troubleshooting

When something's not right

Most problems have a quick fix below. If not, Cinematic can stand down for the session in one command, and hand you everything needed for a bug report in another.

The safety switch

Panic and resume

If Cinematic keeps hitting the same error, it stops itself for the session and puts your UI and game settings back, and says so in chat. You can do the same by hand at any time:

/cine panicStops Cinematic for this session and puts your UI and settings back
/cine resumeStarts it again

It stays stopped for the rest of the session unless you resume it. While it's stopped, /cine on reminds you that it's still stopped after an error.

Quick fixes

Common problems

Cinematic doesn't do anything.
You may not have picked a level yet: until you do, nothing runs. Type /cine welcome and pick one. If you did, it may be off (/cine on), or stopped after an error (/cine resume).
My whole UI is gone and won't come back.
That's the Hide the UI key or /cine hideui. Press the key again, type the command again, or press the game's own Alt+Z.
The minimap button is gone.
Type /cine button, or tick Show minimap button on the main settings page. In CineMode it fades with the minimap: point at the minimap to see it.
Another addon's frame doesn't fade.
Point at it and type /cine add, or use /cine add mode to pick up several. See Other addons.
A frame fades that I want to keep.
Point at it and type /cine keep. For the game's own frames, tick it on the Standard Frames page to keep it up always, in fights or in places.
The camera's at an odd angle.
/cine behind swings it back behind your character and keeps your zoom.
The RP walk camera starts when I run, or not when I walk.
Type /cine walk to see what Cinematic thinks you're doing. If it has walk and run backwards (this can happen after a reload while walking), /cine walk flip fixes it.
The camera keeps moving on its own and I don't want it to.
Pick Never in Customize's Camera area (/cine welcome, then Next), or turn single events off on the Camera Triggers page.
I can't see tooltips.
The Tooltips page is hiding them. Hold your Show hidden tooltips key, press Toggle tooltip hiding, or switch the page off. Both keys are on the Keybinds page.
I turned off floating text and nothing changed.
That one needs a full restart of the game; a /reload isn't enough. It also hides damage and healing numbers.
I changed the language and nothing changed.
Cinematic's language changes after a reload. Type /reload.
I've changed too much and want to start over.
Reset page on any settings page puts just that page back. /cine reset puts the whole active profile back to how it started. Or pick a level again in the welcome window.
My sound or game settings changed.
Cinematic saves your own settings first and puts them back when it's done, even after a crash. If something still looks wrong, /cine panic puts everything back at once.
Still stuck?

Report a bug with /cine log

  1. Make it happen, then type /cine log

    A window opens with the log already selected. It holds Cinematic's recent history, any Lua errors and a summary of your setup: game version, changed settings and other addons. It doesn't include your character's name or realm.

  2. Press Ctrl+C to copy it

    It's long; that's fine.

  3. Paste it into your report

    On GitHub, paste it straight into the form. On Discord it's too long for a message, so save it as a .txt file and attach that.

/cine logOpens the log and your setup, ready to copy
/cine log clearEmpties the log, to start a fresh one before you reproduce the problem
