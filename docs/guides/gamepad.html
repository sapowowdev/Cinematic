Cinematic · Gamepad

Play from the couch

WoW Forever's gamepad mode adds action bars, button hints and an aiming dot of its own. Cinematic fades them with the rest of the UI, and brings the bars back the moment you press a button.

Gamepad mode

What the game adds

WoW ForeverNo Gamepad page on retail

Turn gamepad mode on in the game's Options, under Controls, Gamepad. It brings its own frames: the gamepad action bars, the button hints in the top left, and the reticle, the dot in the middle you aim with. Cinematic's Gamepad page, in the UI Manager group, decides when each shows in CineMode.

Retail's gamepad mode has no frames of its own for Cinematic to fade, so the Gamepad page shows only on WoW Forever. The gamepad fishing button below works wherever the game has gamepad support.

The Gamepad page

Setting it up

The page's grid works like the Standard Frames page: each frame is hidden in CineMode unless ticked. Always shows it the whole time, Combat and Target only while you fight or have something targeted, and the places while you're there.

Gamepad action bars · Button hints (top left) · Reticle (center dot)A row each in the grid.
Experience and reputation barsThese are also on the Standard Frames page. In gamepad mode they follow this page's row; otherwise that one's.
Show the interact prompt (X)The button prompt over things you can use or talk to (your bobber, an NPC) stays up while nameplates fade, so you can see what the gamepad can reach. On to start with.
Show the action bars when you press a buttonGamepad mode's mouseover: any button press brings the bars up, and each press starts the time again. Choose the buttons in Buttons that show them. Presses that make you jump, and presses while you fish, don't count.
Action bar fadingStay after a press (3 seconds to start with), and the bars' own Fade in time and Fade out time, quicker than the rest of the UI.

On the Mouseover groups page, a group can also come up for Gamepad input: pressing a gamepad button.

Fishing

Cast with a button

On the Fishing page, Gamepad: a button casts too makes a button cast Fishing whenever right-click would: in the fish camera with no bobber out, and (if you ticked it) with a pole equipped while standing still. The rest of the time the button does what it usually does. Pick the button: the left face button (X on an Xbox pad, square on a PlayStation one) to start with, or the top, bottom or right one.

A game bug

Avoiding the Settings freeze

In gamepad mode on WoW Forever, closing the Settings window after using an addon's settings (any addon's, not just Cinematic's) can freeze the game. Two ticks on the Gamepad page work round it, both on to start with:

Force reload on Settings exitOnce you've opened a Cinematic page, closing Settings (X, Close, Escape or the gamepad) reloads the UI instead, which closes it without the freeze. Your settings are saved first, as on every reload. Turning it off takes effect after a reload.
Hide the minimap button in gamepad modeUsing Cinematic's minimap button in gamepad mode tends to freeze the game too, so it's hidden while gamepad mode is on and comes back when it's off. Cinematic's settings are still in the game's Settings (AddOns tab), or type /cine.
Questions

Good to know

Where's my minimap button?
Hidden while gamepad mode is on, to avoid a freeze. Untick Hide the minimap button in gamepad mode on the Gamepad page to have it back.
Why did my UI reload when I closed Settings?
That's Force reload on Settings exit, which stops the game freezing as Settings closes in gamepad mode. Nothing is lost: settings are saved before every reload.
The action bars come up every time I jump.
They shouldn't: presses that make you jump never count. If another button brings them up when you'd rather it didn't, untick it under Buttons that show them.
