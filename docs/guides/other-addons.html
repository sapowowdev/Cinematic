Cinematic · Other addons

Your other addons fade too

Meters, timers, action bar addons and whole UI replacements fade with the game's own frames in CineMode. Many are handled out of the box, and anything else you can add by pointing at it.

The Advanced Frames page

How it works

Supported addons are listed on the Advanced Frames page, the ones you have loaded first, then the rest. Like the game's frames on the Standard Frames page, their frames are hidden in CineMode unless ticked:

AlwaysLeaves the addon alone: shown the whole time.
Combat, TargetShows it only while you fight or have something targeted.
LocationShows it in the places you pick, while you're there.
EditTurns the row into a rule of its own, with AND, NOT and more.

The page's Enable page switch turns all of it on or off: off, Cinematic leaves every addon's frames alone.

Everything else

Add it yourself

For any other addon, point at its frame and add it. It joins the Custom frames list at the bottom of the Advanced Frames page, with the same columns as the supported addons.

One frame

  1. Put the mouse over the frame you want to fade.
  2. Type /cine add in the chat box and press Enter. Cinematic says which frame it's now fading.

Several at once: Add mode

  1. Press Pick frames by hovering under Custom frames, or type /cine add mode. Move the settings window out of the way, or close it.
  2. Hover over each frame you want to fade.
  3. Click Stop, or type /cine add mode again, to fade them all. /cine add cancel drops them instead.

The game's own frames, and ones already faded, are left out: they're on the Standard Frames page already. Windows aren't added either, since a faded window would sit there invisible. A frame its addon didn't give a name can't be added; if one of yours won't, ask for it to be supported.

Keeping one up instead

To keep a frame that fades on screen the whole time, hover over it and type /cine keep. To undo it, untick its CineMode box under Custom frames.

Commands

Frame commands

Hover over a frame first, then type these in the chat box.

/cine addFades the frame under the mouse too. Or name it: /cine add FrameName
/cine add modePicks up every frame you hover over; again to fade them all
/cine keepAlways shows the frame under the mouse
/cine listShows the extra frames you've had faded
Questions

Good to know

An addon is on the list but still shows in CineMode.
Check its row on the Advanced Frames page (or, for one that follows the Standard Frames page, the row of the frame it replaces): with Always ticked, it stays up.
I use EllesmereUI's or ElvUI's action bars. Where are they?
Most are the same rows as the game's bars on the Standard Frames page, so they fade just as the game's would. Only the extra bars the game doesn't have get rows on the Advanced Frames page.
/cine add says it's a window.
Move the mouse off the window, onto the frame you want, and try again. Windows aren't faded so you never lose one you opened.
